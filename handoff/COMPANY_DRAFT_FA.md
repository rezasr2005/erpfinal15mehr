تغییرکرده: محتوای معرفی و کامپوننت و CSS دربارهٔ ما؛ محتوا و کامپوننت و CSS تماس و ContactChannel؛ محتوا و کامپوننت و CSS انبار؛ مسیر clients؛ Footer و public-shell.css. مسیرها نسبت به `source/apps/web` هستند.

## اجرا

فایل ZIP را استخراج و `source` را به‌عنوان ریشهٔ پروژه باز کنید. Node.js 22.12+ و pnpm 11.19.0 لازم‌اند. ابتدا `pnpm install --frozen-lockfile`، سپس از `source/apps/web`:

```bash
node node_modules/next/dist/bin/next dev --hostname 127.0.0.1
```

سایت عمومی به API و PostgreSQL نیاز ندارد. سورس کامل، manifest تازه و patch نسبت به فایل انتقال اولیه در بسته موجودند. وابستگی‌ها، env واقعی و خروجی build در بسته نیستند. این نسخه روی اینترنت منتشر نشده است.
