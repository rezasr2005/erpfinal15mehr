## بازبینی بعدی منابع

ابزار مستقل بدون وابستگی جدید:

```bash
cd /workspace/erpfinal15mehr
python source/scripts/research-public-channels.py --output /tmp/kavian-public-posts.json
python source/scripts/research-public-channels.py --channel kaviankhavarshahr403 --before 395 --output /tmp/kavian-older-posts.json
```

هر دو دستور در محیط واقعی اجرا و نتیجه دریافت شدند. ابزار فقط پیش‌نمایش عمومی را می‌خواند؛ ارسال، ورود، دانلود خودکار رسانه یا تغییر نرخ سایت ندارد. عددهای روی تصویر از متن پیام قابل استخراج قطعی نیستند و باید تصویر، واحد، تاریخ و نسخه‌های متفاوت بررسی شوند. قالب HTML ممکن است تغییر کند؛ خروجی بدون پیام یا شکست شبکه، exit غیرصفر دارد. URL رسانه ممکن است موقت باشد؛ برای تصویرِ پذیرفته‌شده از فایل محلی با SHA256 استفاده شود.

## بررسی نسخهٔ نهایی

Build، TypeScript و ESLint موفق‌اند. مرورگر برای ۱۲ مسیر تغییرکرده در دو زبان و پنج عرض ۳۲۰،۳۷۵،۷۶۸،۱۱۰۰،۱۴۴۰ مجموعاً ۶۰ مشاهده ثبت کرد: HTTP 200، عنوان و زبان درست، یک h1، نبود سرریز و بارگذاری تمام تصاویر. ۲۰ بررسی معنایی شامل منابع دقیق، حفظ جدول قبلی، موجودی فعال خالی، تعداد اطلاعیه‌ها، مخاطب صحیح ایمیل/واتساپ، حفظ فارسی و علامت‌های متن و کپی به clipboard موفق بودند. ارسال واقعی پیام انجام نشد.

مسیر تصاویر واکنش‌گرای پوسترها در بررسی اولیهٔ Chromium در ۱۴۴۰ بارگذاری را آغاز نکرد؛ همان فایل‌های محلی مستقیم سالم بودند. برای این سه پوستر از گزینهٔ supported `unoptimized` استفاده شد و بررسی کامل مجدداً موفق شد. این تصمیم فقط همین سه فایل را شامل می‌شود. تصاویر موبایل واقعی مرورگر برای چیدمان آرشیو و استعلام مشاهده شدند؛ تصاویر کامل عنصر در اسکرول طولانی بعضی آثار تصویربرداری داشتند و نتیجهٔ نمای viewport مبنا قرار گرفت.

## نتیجهٔ جست‌وجوی تکمیلی اطلاعات ثبتی

فهرست عمومی hacinhaseb.com با نام دقیق «فولاد کاویان سپنتا»، شناسهٔ ملی ۱۴۰۰۷۵۹۰۴۵۶ و شمارهٔ ثبت ۵۲۶۲۹۰ را گزارش می‌کند. متن بازنشر آگهی، نشانی ثبتیِ طبقهٔ ۳ در پلاک ۶ کوچهٔ مسجد، خیابان مسجد، شهرک نفت تجریش را طبق صورتجلسهٔ ۱۴۰۳/۰۷/۲۵ ذکر می‌کند. این منبع ثانویه است؛ تطبیق با مرجع رسمی ثبت و شرکت همین پروژه انجام نشده است. شماره‌ها و نشانی فقط به‌عنوان یافتهٔ پژوهش ثبت شدند و به سایت منتقل نشدند. نشانی ثبتی الزاماً نشانی مراجعه یا دفتر عملیاتی نیست؛ اطلاعات قبلی صاحب پروژه حفظ شد. این صفحه ساعات کاری، نقشهٔ تأییدشده یا عکس واقعی انبار ارائه نمی‌کند.
